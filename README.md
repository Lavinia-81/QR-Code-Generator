# QR Code Generator
HTML • CSS • JavaScript — Generate & Download Custom QR Codes  
Live Demo: https://lavinia-81.github.io/QR-Code-Generator/

A simple and responsive QR code generator built using vanilla JavaScript, HTML, and CSS.
This project was created out of curiosity and experimentation, and it demonstrates how external libraries can be integrated into front‑end applications to generate dynamic content.

---

## Overview
QR Code Generator allows users to create QR codes for any text or URL, customize their size, and download them as images.

It showcases essential front‑end concepts such as:
- DOM manipulation
- event handling
- dynamic rendering
- integration with third‑party libraries (qrcodejs)
- responsive UI design

Even though it is a beginner project, it remains a valuable milestone in your JavaScript learning journey.

---

## Features
### QR Code Generation
- Generate QR codes for any text or URL
- Choose from multiple size options
- Real‑time rendering of the QR code

### Download Functionality
- Download the generated QR code as a PNG image
- Ensures high‑quality output regardless of size

### UI & Design
- Clean and responsive layout
- Simple and intuitive interface
- CSS‑based styling

### JavaScript Logic
- Event handling for button clicks
- Input validation
- Integration with qrcodejs
- Dynamic DOM updates

## How to Use
- Open index.html in your browser.
- Enter any text or URL in the input field.
- Select the desired QR code size.
- Click Generate to create the QR code.
- Click Download to save the QR code as an image.
